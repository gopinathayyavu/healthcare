# HealthCar — Premium Wellness Website

A high-performance, multi-page wellness website rebuilt from the supplied reference project and rebranded as HealthCar.

## Highlights
- Premium animated hero with CSS 3D wellness orb
- Lightweight canvas particle field
- Mouse-responsive hero depth/parallax
- Immediate call / WhatsApp / booking contact rail directly below hero
- Floating quick-contact actions
- Animated scroll reveals
- Service carousel with 3D depth
- Review carousel with responsive behavior
- Responsive mobile navigation
- Lazy-loaded imagery and local WebP assets
- Accessible reduced-motion fallback
- SEO-ready page metadata
- Booking form with service preselection
- Multi-page architecture: Home, About, Experiences, Events, Journal, Partners, Contact, Privacy, Terms

## Run

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.
